# 创业咖啡馆本机内测验收

2026-11-23。所有账户和对话均为测试数据。可复跑的规则、传输、浏览器和语言测试在 tests 目录。

| 实测 | 结果 |
|---|---|
| 房间与服务 | 14 项自动测试通过。含 51 个独立 HTTP 会话与 WebSocket 连接，最后一席同时申请只成功一个，50 听众和 1 讲者共存。测试时钟跨越 15 分钟，连续两轮各 11 票正常续讲，第 3 轮 10 票交台。 |
| 浏览器 | 同一台 Mac 的 Chrome 启动三个隔离身份，分别操作讲者、协作者和旁观者。实际点击入座、申请和确认上台、中英对话、开麦、主动收听、发布合作卡、接受提议与私信；第三人看不到该提议或私聊。 |
| 会后 | 两位参与者分别确认下一步并在界面看到 2/2；刷新后可找回合作。没有真实买方、外部参与者或真实合作结果。 |
| 手机布局 | 390 像素宽的 Chrome 视口通过横向溢出检查。属于桌面 Chrome 的手机尺寸模拟。 |
| 双语文字 | 10 句中译英、10 句英译中。逐句对照原意，20 句均保留主要意思。测试覆盖否定、费用、日期、数字与人名。 |
| 语音字幕 | 两种系统合成声音，经实时音频包、服务器识别、客户端取译文。按原意复核，17/20 保留。偏差涉及“在找／再找”、“有偿／有长”及 Python 项目名。详见逐句结果。 |
| 字幕修订 | 讲者在真实 Chrome 的已发布语音字幕上更正文字，另一端中文界面自动更新翻译。合作卡的报酬类型、金额与币种有独立字段。 |
| 本地启动与关闭 | 启动器、健康检查、关闭器、再次启动均实测成功。默认监听 127.0.0.1。项目运行目录与 AVOS 数据库、Git 工作树和巡检任务分开。 |

第一轮 51 会话测试发现同一网络批量入场会误触凭证限流。已将限流限于无效凭证，重新验证 51 个独立身份通过。初版翻译将“还没有付费客户”误译成尚未给客户付款。在本机确认系统已安装中英离线语言后，采用系统翻译为首选、OPUS-MT 为离线备用，并提升识别模型。备用引擎的语言质量与首选引擎有差异。

文字和语音延迟的逐句毫秒数、统计口径与语义偏差均保存在 language-results.json。当前覆盖单机传输、合成语音、桌面 Chrome，未测两台实体设备异地通话、真实口音或同场 50 台设备的音质。三场真人内测尚未进行，公网服务尚未发布。
